# Food--Waste-Prediction-System
Food Waste Prediction System is a beginner-friendly ML project using Python, Pandas, NumPy, Matplotlib, Scikit-learn, Pickle, and Streamlit. It predicts food waste in kg, estimates financial loss in INR, USD, EUR, GBP, AED, CAD, and AUD, and provides reduction recommendations. It includes prediction, EDA, data exploration, and model R2 for kitchens
